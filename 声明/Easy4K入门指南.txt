                        Easy4K 入门指南
════════════════════════════════════════════════════════════════════

欢迎使用 Easy4K 视频超分辨率与补帧处理软件。
本指南帮助您在安装完成后快速上手。

────────────────────────────────────────────────────────────────────
一、快速开始（五步完成第一次处理）
────────────────────────────────────────────────────────────────────
1. 选择输入视频：
   点击"浏览"选择视频文件（支持 MP4 / MKV / AVI / MOV），
   或使用快捷键 Ctrl+O。软件会自动检测分辨率、帧率与时长。
2. 确认处理项目：
   勾选您需要的处理功能（详见下文"二、功能说明"）。
3. 选择模型与倍率：
   - 超分倍率（×2/×3/×4）选择后，可用模型会自动过滤；
   - 补帧模型按您的显存情况选择。
4. 确认输出目录：
   成品视频将输出到"输出目录"（默认在软件 Output 文件夹），
   可点击"浏览"修改。
5. 点击"开始处理 (Ctrl+S)"：
   处理开始后自动进入"进行中"页面，可实时查看进度、预览画面
   与命令日志；点击"暂停/继续"可挂起或恢复处理，点击"停止"
   可终止本次处理。

────────────────────────────────────────────────────────────────────
二、功能说明
────────────────────────────────────────────────────────────────────
1. 拆帧：将视频分解为逐帧图片，是后续超分/补帧的基础。
2. 超分（×2/×3/×4）：使用 Real-ESRGAN 将画面放大并增强细节。
   - 动漫视频推荐 realesr-animevideov3 系列；
   - 通用视频推荐 realesrgan-x4plus 系列。
3. 补帧（×2~×5）：使用 RIFE 提高视频帧率，使画面更流畅。
   "补帧设置 → 种类"可选两种引擎：
   - NCNN（默认）：rife-ncnn-vulkan，Vulkan 全 GPU 通用、速度快；
   - Offical：官方 PyTorch 模型（pkl 文件），画质更接近官方实现。
     支持 CUDA 的 NVIDIA 显卡自动 GPU 加速；无 CUDA 的设备
     （如 AMD）自动降级 CPU 推理，速度较慢，"进行中"页会标注
     "（降级）"。
   NCNN 常规模型 rife-v4.6 / v4.18 / v4.22-lite（6GB 显存及以上）；
   高质量模型 rife-v4.25 / v4.26（需 8GB+ 显存）。
4. 合并：将处理后的帧序列重新合成为视频。
5. 音频：勾选"合并原音频"可将原视频音频合入成品（自动提取）。
6. SDR→HDR：将画面转换为 HDR（仅支持 NVIDIA RTX 20/30/40/50
   系列显卡，其他显卡自动禁用）。

   【处理流水线】拆帧 → 超分 → 补帧 → 合并 → 嵌入音频 → HDR
   已完成的步骤下次运行会自动跳过，无需重复处理。

   【高级性能选项】（"高级性能选项"面板）
   - 处理线程：NCNN 对应 -j 1:x:x；Offical 对应 PyTorch 推理线程；
   - 安全帧率：遇到设备丢失/显存/内存溢出时强制停止（两种引擎均生效）；
   - 降低部分画质（-u）：NCNN UHD / Offical FP16，可与安全帧率共存；
   - FFmpeg GPU 加速：拆帧解码 -hwaccel、合并帧 GPU 编码器优先
     （NVIDIA NVENC → AMD AMF → Intel QSV），失败自动回退 CPU。

────────────────────────────────────────────────────────────────────
三、帧文件夹模式（可选进阶用法）
────────────────────────────────────────────────────────────────────
您也可以不选视频，直接导入一个"帧文件夹"（含 PNG 图片序列）：
1. 点击"导入帧文件夹"并选择图片所在文件夹；
2. 在弹出的窗口中填写 分辨率宽高 / 图片张数 / 原视频帧率；
3. 确认后即可按普通流程超分、补帧、合并。
   （帧文件夹模式下"合并原音频"不可用）

四、快捷键
────────────────────────────────────────────────────────────────────
   Ctrl+O        打开视频
   Ctrl+S        开始处理
   Ctrl+Shift+S  停止处理
   Ctrl+L        清空日志
   F1            帮助
   Alt+F4        退出

────────────────────────────────────────────────────────────────────
五、菜单功能
────────────────────────────────────────────────────────────────────
1. 工具 → 环境检测：检查 FFmpeg / Real-ESRGAN / RIFE 等工具
   是否就绪；
2. 工具 → 显卡检测：查看显卡型号、显存、是否支持 HDR；
3. 工具 → 清理临时文件：删除临时目录中的帧与中间产物
   （含两次确认，可放心使用）；
4. 设置 → 主题：切换 浅色 / 深色 / 跟随系统 / 亚克力；
5. 设置 → 保存设置：保存当前模型与倍率等偏好；
6. 帮助 → 使用说明 / 快捷键 / 关于：查看本指南与版本信息。

────────────────────────────────────────────────────────────────────
六、常见问题
────────────────────────────────────────────────────────────────────
Q1：提示"临时目录缓存不符"怎么办？
A：当前临时目录中留有其他视频的旧缓存。可选择"重新选择临时
   目录"换到新目录，或点击"清理缓存"删除旧缓存后再启动。

Q2：处理时进度条停在某处不动？
A：AI 处理受显卡负载影响，处理大数据量时速度下降属正常现象；
   使用 Offical 引擎且无 CUDA 设备时会降级为 CPU 推理，速度明显
   变慢属正常（"进行中"页标注"（降级）"）；可查看命令输出区
   判断是否仍在正常输出。

Q3：提示检测到 Vulkan 设备丢失 / 显存溢出？
A：多为显存不足所致。可改用显存占用更低的模型
   （如 RIFE -lite 系列），或适当降低线程数后重试。

Q4：成品视频在哪个位置？
A：输出目录（默认 Output 文件夹）内，文件名会标注分辨率、
   帧率、倍率等参数信息。

Q5：处理完成后残留的临时文件如何清理？
A：处理完成弹窗中可选择清理；也可随时在"工具 → 清理临时文件"
   中清理，该操作会删除中间帧与缓存。
