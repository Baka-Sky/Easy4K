三、【详细描述】（Description 字段，限 10000 字符）
────────────────────────────────────────────────────────────────────
Easy4K 是一款面向普通用户的 Windows 视频画质提升工具，把原本需要多款命令行工具、来回折腾参数的超分辨率与补帧流程，整合成一条可视化流水线：选择视频、勾选要做的步骤、点「开始处理」，剩下的交给它。

【一条流水线，四件事一起做完】
★ 拆帧：用 FFmpeg 按原始画质逐帧导出 PNG（可选 GPU 硬解加速）
★ AI 超分：集成 Real-ESRGAN，把画面放大 2 倍 / 3 倍 / 4 倍，含动漫与实拍多套模型
★ AI 补帧：集成 RIFE 两种引擎（NCNN 与官方 PyTorch 实现），提升帧率、让动作更顺滑
★ 合并与音频：把处理后的画面合成新视频，并自动嵌入原音轨；NVIDIA RTX 用户还可开启 SDR→HDR 转换

【v2.0 新增的高级能力】
☆ 高级模式页：标准 / 高级一键切换，高级页集中放置需要斟酌的进阶功能
☆ 帧去重：自研四阶级联判决算法（像素差粗筛 → dHash 细筛 → QR 分解精判 → Farnebäck 稠密光流终判），自动识别定格画面并剔除重复帧，避免在静止画面上浪费算力；提供「性能」「完美」两档，并可查看算法详解
☆ 音频超分：基于 AudioSR 扩散模型重建高频，把音轨升采样到 48kHz 直出并嵌入视频，提供 FP16 性能档与 FP32 完美档
☆ 多语言界面：简体中文 / 繁体中文 / 日语 / 韩语 / 英语；主题支持浅色 / 深色 / 跟随系统，可用自定义背景图片与亚克力材质
☆ 处理前测试：先跑一段 1 秒测试视频按当前勾选验证流程是否可用，通过后自动衔接正式处理，避免长时间跑完才发现失败

【用得放心的细节】
· 实时反馈：每阶段独立进度条 + 逐帧计数 + 实时日志，处理中还能预览最新画面，并显示 CPU / GPU 占用
· 断点续传：已完成的阶段自动跳过，中断后重开可复用中间结果
· 安全帧率：遇到设备丢失、显存或内存溢出时自动停止，保护显卡；异常时自动降级单线程重试
· 三种引擎可切：补帧支持 NCNN 与官方 PyTorch 引擎，没有 CUDA 的设备自动改用 CPU 推理并在界面标注「降级」
· 硬件加速可关：FFmpeg 解码 / 编码可用 GPU（NVENC / AMF / QSV），失败自动回退 CPU 并明确提示
· 临时文件一键清理：清理中间产物并给出结果；检测到遗留文件时启动前弹窗引导
· 关闭保护：处理中关窗会二次确认，确认后强制结束全部子进程
· 环境检测与版本检查：内置显卡 / 环境检测，提前看清能否开跑
· 处理报告：可选生成 HTML 报告，记录本次处理的参数与结果
· 首次使用向导：7 步引导完成基本设置，随后即可上手

六、【系统要求】（System requirements 字段）
────────────────────────────────────────────────────────────────────
操作系统：Windows 10 版本 1809（2018 年 10 月更新）或更高版本 / Windows 11；仅支持 64 位（x64）
处理器：64 位处理器，建议 4 核及以上
内存：建议 8GB 及以上，16GB 更佳
显卡：支持 Vulkan 1.1 及以上的 GPU（NVIDIA / AMD / Intel 均可）用于超分与补帧；
      补帧官方引擎在支持 CUDA 的 NVIDIA 显卡上启用 GPU 加速，无 CUDA 设备自动回退 CPU；
      SDR→HDR 转换仅支持 NVIDIA RTX 20/30/40/50 系列（非 RTX 自动禁用，不影响其他功能）；
      音频超分需显卡驱动支持 DirectML
显存：建议 4GB 及以上；跑高规格补帧模型建议 8GB 以上
磁盘：软件本体约 6.5GB（含全部 AI 模型权重与便携运行库）；
      处理过程会在临时目录生成逐帧图片，请预留充足空间（建议不低于预估中间文件总量的 1.5 倍）

   Easy4K is a desktop video-processing application packaged as MSIX.
   Its core functionality requires launching third-party command-line

■ 视频处理能力
· 视频超分：集成 Real-ESRGAN（动漫 realesr-animevideov3 x2/x3/x4、
  realesrgan-x4plus、x4plus-anime），支持 2/3/4 倍放大与模型按倍率过滤
· 视频补帧：双引擎
  - NCNN（rife-ncnn-vulkan）：v2 / v3 / v4.6 / v4.18 / v4.22-lite /
    v4.25 / v4.26（含 heavy）等 40 余个模型
  - 官方（PyTorch）：2.3、4.6~4.26、RPR v7 等 10 余个模型（含移植版）
· 官方引擎设备自适应：检测 CUDA，可用则 GPU 加速，不可用（如 AMD）
  自动改用 CPU 推理，并在阶段文字标注「（降级）」
· 拆帧 / 合并 / 音频嵌入：FFmpeg；合并支持 libx265、CRF 18，可选
  GPU 编码器（NVENC / AMF / QSV）优先，失败自动回退 CPU 并提示
· SDR→HDR 转换：NVEncC（RTX 20/30/40/50 系列），非 RTX 自动禁用
· 音频：默认提取原音轨嵌入新视频（PCM 24bit）；音频超分开启后由
  AudioSR 重建高频并 48kHz 直出，不再走普通重采样
· 帧去重（自研）：四阶级联判决 —— 像素差粗筛 → dHash 细筛 →
  QR 分解精判 → Farnebäck 稠密光流终判；提供「性能」「完美」两档
· 音频超分：AudioSR 扩散模型（ONNX + DirectML），FP16 性能档与
  FP32 完美档；FP16 与 CPU 处理模式互斥并弹窗拦截
· 处理顺序：拆帧 → 超分 → 补帧 → 帧去重 → 音频超分 → 合并 → HDR
