三、【详细描述】（Description 字段，限 10000 字符）
────────────────────────────────────────────────────────────────────
Easy4K 是一款面向普通用户的 Windows 视频画质提升工具，把原本需要多款命令行工具、来回折腾参数的超分辨率与补帧流程，整合成一个可视化流水线：选择视频、勾选要做的步骤、点「开始处理」，剩下的交给它。

【一条流水线，四件事一起做完】
★ 拆帧：用 FFmpeg 按原始画质逐帧导出 PNG（可选 GPU 硬解加速）
★ AI 超分：集成 Real-ESRGAN，把画面放大 2 倍 / 3 倍 / 4 倍，含动漫与实拍多套模型
★ AI 补帧：集成 RIFE 两种引擎（NCNN 与官方 PyTorch 实现），提升帧率、让动作更顺滑
★ 合并与音频：把处理后的画面合成新视频，并自动嵌入原音轨；NVIDIA RTX 用户还可开启 SDR→HDR 转换

【v2.0 新增的高级能力】
☆ 高级模式页：标准 / 高级一键切换，高级页集中放置需要斟酌的进阶功能
☆ 帧去重：自研四阶级联判决算法（像素差粗筛 → dHash 细筛 → QR 分解精判 → Farnebäck 稠密光流终判），自动识别定格画面并剔除重复帧，避免在静止画面上浪费算力；提供「性能」「完美」两档，并可查看算法详解
☆ 音频超分：基于 AudioSR 扩散模型重建高频，把音轨升采样到 48kHz，提供 FP16 性能档与 FP32 完美档
☆ 多语言界面：简体中文 / 繁体中文 / 日语 / 韩语 / 英语
☆ 主题与外观：浅色 / 深色 / 跟随系统，支持自定义背景图片与亚克力材质
☆ 处理前测试：先跑一段 1 秒测试视频按当前勾选验证流程是否可用，通过后自动衔接正式处理，避免长时间跑完才发现失败

【用得放心的细节】
· 实时进度：每阶段独立进度条 + 逐帧计数 + 实时日志，处理中还能预览最新画面
· 断点续传：已完成的阶段自动跳过，中断后重开可复用中间结果
· 安全帧率：遇到设备丢失、显存或内存溢出时自动停止，保护显卡
· 临时文件清理：一键清理中间产物；检测到遗留文件时启动前弹窗引导
· 关闭保护：处理中关窗会二次确认，确认后强制结束全部子进程
· 环境检测：内置显卡 / 环境检测，提前看清能否开跑
· 处理报告：可选生成 HTML 报告，记录本次处理的参数与结果

【隐私说明】
软件仅在您首次启动时询问一次是否同意上传匿名统计信息（软件启动时间、本次开启的功能、软件版本、Windows 版本、所在地区）；不同意同样可以完整使用全部功能，且不会再次询问。不采集视频音频内容、文件名、文件路径、用户名、账号，也不做 IP 定位。

四、【产品功能】（Product features 字段，最多 20 条，一条一行）
────────────────────────────────────────────────────────────────────
AI 超分：Real-ESRGAN 集成，支持 2/3/4 倍放大与多套动漫、实拍模型
AI 补帧：RIFE 双引擎（NCNN 与官方 PyTorch），提升帧率让动作更顺滑
帧去重：四阶级联判决自动识别定格帧，避免重复帧浪费算力
音频超分：AudioSR 扩散模型重建高频，音轨升至 48kHz
SDR→HDR 转换：NVIDIA RTX 显卡可开启，拓展动态范围
一键流水线：拆帧、超分、补帧、合并、嵌音、HDR 全自动衔接
GPU 硬件加速：Vulkan 计算加速，FFmpeg 编解码可选 GPU 加速并自动回退
CPU 处理模式：显卡不可用时可全程 CPU 推理
实时进度与预览：分阶段进度条、逐帧计数、实时日志与画面预览
断点续传：已完成的阶段自动跳过，中断后重开复用中间结果
临时文件一键清理：清理中间产物并给出结果提示
处理前测试：先用 1 秒测试片验证当前流程，通过后再正式开跑
关闭保护与安全帧率：异常时自动停止，保护显卡
HTML 处理报告：记录参数与结果的图文报告
多语言界面：简体中文、繁体中文、日语、韩语、英语
主题与外观：浅色、深色、跟随系统，支持背景图片与亚克力材质
配置持久化：模型、倍率、线程、目录等设置自动保存

五、【此版本的新增功能】（What's new 字段，限 1500 字符）
────────────────────────────────────────────────────────────────────
v2.0.0 是 Easy4K 的一次大版本更新：

新增
· 全新「高级模式」页：标准 / 高级一键切换，集中管理进阶功能
· 帧去重：自研四阶级联判决算法（像素差粗筛 → dHash → QR 分解 → Farnebäck 光流），自动剔除定格重复帧，提供性能 / 完美两档与算法详解
· 音频超分：基于 AudioSR 重建高频并将音轨升至 48kHz，提供 FP16 性能档与 FP32 完美档；开启后音频不再经普通重采样，直接高质量直出并嵌入视频
· 多语言界面：简体中文 / 繁体中文 / 日语 / 韩语 / 英语
· 设置页与图片背景主题（含亚克力材质）
· 处理前测试：先用 1 秒测试片按当前勾选验证流程
· 可选不生成 HTML 处理报告
· 新增匿名统计开关：首次启动弹窗询问一次，可拒绝且不影响功能

修复
· 帧去重误删：修正第 1 阶判决漏判小面积运动元素的问题，此前会把镜头中局部运动的画面误判为定格并删除，1080p 实测误删率由 89.5% 降至 19.3%
· 音频超分进度长期显示 0%、进度文字未标注 FP16 / FP32 模式
· 超分与 NCNN 补帧的「降低部分画质」勾选无效（未传 -u 参数）
· 显存单位与 RTX 系列说明文案有误
· 「清空日志」在页面切换后不同步、事件重复订阅
· 中断残留清理提示文案易误解（不再出现「因意外导致关闭」字样）
· 首次向导若干界面崩溃与文字截断问题
· CPU 处理模式相关弹窗反复弹出、倍率选项禁用状态反了等问题
· SDR→HDR 参数调节未真正生效

其他
· 以 MSIX 安装包形式发布，安装卸载更规范

六、【系统要求】（System requirements 字段）
────────────────────────────────────────────────────────────────────
操作系统：Windows 10 版本 1809（2018 年 10 月更新）或更高版本 / Windows 11；仅支持 64 位（x64）
处理器：64 位处理器，建议 4 核及以上
内存：建议 8GB 及以上，16GB 更佳
显卡：支持 Vulkan 1.1 及以上的 GPU（NVIDIA / AMD / Intel 均可）用于超分与补帧；
      补帧官方引擎在支持 CUDA 的 NVIDIA 显卡上启用 GPU 加速，无 CUDA 设备自动回退 CPU；
      SDR→HDR 转换仅支持 NVIDIA RTX 20/30/40/50 系列（非 RTX 自动禁用，不影响其他功能）；
      音频超分需显卡驱动支持 DirectML
显存：建议 4GB 及以上；跑高规格补帧模型建议 8GB 以上
磁盘：软件本体约 6.5GB（含全部 AI 模型权重与便携运行库）；
      处理过程会在临时目录生成逐帧图片，请预留充足空间（建议不低于预估中间文件总量的 1.5 倍）
其他：建议将显卡驱动更新至最新版本
