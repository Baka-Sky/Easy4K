                    Easy4K 安装前必读 —— 系统要求
════════════════════════════════════════════════════════════════════

感谢您使用 Easy4K 视频超分辨率与补帧处理软件。
在安装前，请先确认您的电脑满足以下运行要求，以避免处理中断、
运行缓慢或显存不足等问题。

────────────────────────────────────────────────────────────────────
一、操作系统要求
────────────────────────────────────────────────────────────────────
1. Windows 10 版本 1809（2018 年 10 月更新）或更高版本；
   推荐使用 Windows 10 21H2 / Windows 11。
2. 仅支持 64 位操作系统（x64）。
3. 请确保显卡驱动已更新至最新版本。

────────────────────────────────────────────────────────────────────
二、硬件要求
────────────────────────────────────────────────────────────────────
1. CPU：64 位处理器，建议 4 核及以上。
2. 内存：建议 8GB 及以上（处理长视频或高分辨率视频时占用较高）。
3. 显卡（GPU）：
   - 超分（Real-ESRGAN）与补帧（RIFE）均基于 Vulkan 计算，
     需要显卡及驱动程序支持 Vulkan 1.1 及以上；
   - NVIDIA、AMD、Intel 支持 Vulkan 的显卡均可使用超分与补帧；
   - 显存越大，可使用的模型与处理速度越理想。
   - 补帧引擎"Offical"（官方 PyTorch 模型）：支持 CUDA 的 NVIDIA
     显卡自动启用 GPU 加速；无 CUDA 的设备（如 AMD）自动使用 CPU
     推理，速度显著低于 GPU，属正常现象（界面会标注"（降级）"）。
4. SDR→HDR 转换功能（可选）：
   - 仅支持 NVIDIA RTX 20/30/40/50 系列显卡；
   - 非 RTX 显卡该功能自动禁用，其余功能不受影响。

────────────────────────────────────────────────────────────────────
三、显存与内存要求（按模型）
────────────────────────────────────────────────────────────────────
1. 超分模型（Real-ESRGAN）：
   - realesr-animevideov3-x2 / x3 / x4（动漫视频，推荐）
   - realesrgan-x4plus / realesrgan-x4plus-anime（通用/动漫 4 倍）
   - 显存要求：无强制下限，建议 4GB 及以上可获得较好速度。
2. 补帧模型（RIFE）：
   - NCNN 引擎：rife-v4.6 / v4.18 / v4.22-lite 等常规模型建议
     显存 6GB 及以上；rife-v4.25 / v4.26（含 heavy）需 8GB 以上，
     显存不足时改用 -lite 系列；
   - Offical 引擎（PyTorch pkl）：2.3 / 4.6~4.26 / RPR v7 等官方
     模型；NVIDIA CUDA 显卡 GPU 加速，AMD 等无 CUDA 设备自动 CPU。
3. 内存：上述模型均建议系统内存 8GB 及以上，16GB 更佳。

────────────────────────────────────────────────────────────────────
四、磁盘空间要求
────────────────────────────────────────────────────────────────────
处理过程中会在临时目录生成逐帧 PNG 图片，占用空间按视频大小
放大若干倍：

1. 拆帧：每帧 PNG 约 2MB（1080p）/ 8MB（4K）；
2. 超分：额外生成每帧约 8MB 的 4K 帧；
3. 补帧：按倍率额外生成（×2/×4 等）。

请确保临时目录所在磁盘留有足够的可用空间
（建议不低于预估中间文件总量的 1.5 倍）。

────────────────────────────────────────────────────────────────────
五、安装说明
────────────────────────────────────────────────────────────────────
1. 将 Easy4K 整个文件夹（含 Easy4K.exe 及 Tools 目录）复制或解压
   到您希望安装的位置；
2. 请务必保证 Tools 文件夹与 Easy4K.exe 位于同一目录下，且目录
   名称保持为"Tools"，切勿拆分或改名；Offical 补帧引擎随附便携
   Python 运行环境（Tools\officalrife），无需另行安装 Python；
3. 双击 Easy4K.exe 即可运行，无需安装程序，无需联网激活；
4. 首次运行可点击菜单"工具 → 环境检测 / 显卡检测"确认本机环境。

────────────────────────────────────────────────────────────────────
六、免责提示
────────────────────────────────────────────────────────────────────
本软件按"现状"提供，具体运行表现受您的硬件、驱动与系统环境影响。
详细的免责条款请参阅随包《Easy4K 软件安装及使用声明》。
