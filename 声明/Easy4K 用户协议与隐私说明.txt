二、软件说明
────────────────────────────────────────────────────────────────────
1. 本软件是一款 Windows 桌面端"视频超分补帧"工具，基于 WinUI 3 /
   Windows App SDK 开发，运行于 Windows 10 1809 及以上版本（x64）。
2. 处理流程：拆帧 → 帧去重 → 超分 → 补帧 → 合并视频 → SDR→HDR →
   音频超分 → 嵌入音频。各阶段均可独立开关，也可只做其中一步
   （支持单张图片超分与单条音频超分）。
3. 硬件要求：
   · 超分与 NCNN-RIFE 补帧：需支持 Vulkan 的显卡（NVIDIA / AMD /
     Intel 均可）；
   · PyTorch 轨补帧（RIFE / DRBA / GMFSS / GIMM-VFI）与 AudioSR 的
     CUDA 加速：需 NVIDIA 显卡；
   · 无独显时可选 CPU 模式，速度很慢，仅作应急。
4. 超分与补帧对硬件要求较高，处理过程会长时间、满负荷占用
   CPU / GPU / 内存资源。

五、隐私说明（重要）
────────────────────────────────────────────────────────────────────
本软件**默认不采集任何数据**，所有视频与音频处理均在本机完成。
本软件存在两类网络行为，均在下文如实说明。

1. 检查更新（默认开启）
   · 时机：软件启动后自动执行一次。
   · 行为：向 https://update.baka233.top/Easy/Version.txt 发起一次
     GET 请求，读取服务器上的最新版本号；若服务器版本更高，再读取
     Log.txt 以显示更新日志并弹窗提示。
   · **不发送任何数据**：不会上传您的视频、音频、文件名、路径、
     设置或任何可识别信息；请求内容仅为一个普通的网页读取。
   · 网络失败时静默跳过，不影响使用。
   · 如您不希望软件联网检查更新，可用防火墙阻止本软件访问网络；
     这不会影响任何处理功能（超分 / 补帧 / 音频超分全部在本机离线
     完成）。

2. 匿名使用统计（**默认关闭**，需您明确同意后才会上报）
   · 触发时机：首次进入主界面时会弹窗询问；**只有您点击"同意"后
     才会上报**，点击"拒绝"则完全不上报。
   · 上报时机：同意之后，每次点击「开始处理」时上报一条。
   · **上报内容仅以下 5 项**：
       ① 软件启动时间
       ② 本次开启的功能清单（如：超分、补帧、帧去重、音频超分…）
       ③ Easy4K 版本号
       ④ Windows 版本（产品名 + 版本号 + 内部版本号 + x64/x86）
       ⑤ 所在地区（读取系统区域设置里的国家 / 地区代码）
   · **绝不收集**：视频 / 音频内容、文件名、文件路径、电脑用户名、
     账号信息、IP 地址、硬件序列号等任何可识别到个人的信息。
   · 第 ⑤ 项为**本地读取系统区域设置**，不发起定位请求、不通过 IP
     推断地理位置。
   · 用途：仅用于统计功能使用情况与系统兼容性，帮助定位问题、
     改进软件；不用于任何其他用途，不对外提供或出售。
   · 该项为**一次性选择**，仅在首次进入主界面时询问一次。若您已选择
     同意、之后希望停止上报，可编辑本机配置文件 appsettings.json 中
     的 "TelemetryConsent" 字段（改为 "declined"），或联系开发者
     协助关闭。

3. 本地数据
   · 所有处理均在本机完成，处理内容不会离开您的设备。
   · 软件设置保存在本机；卸载本软件后随程序目录一并清除
     （您自行另存到其他位置的文件除外）。

4. 商店上架说明
