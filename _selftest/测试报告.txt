四、发现并修复的问题
------------------------------------------------
1. [严重] 超分子目录模型加载失败
   - 现象: realesr-animevideov3-x3/x4、realesrgan-x4plus、x4plus-anime 全部无法加载
   - 根因: 随附的 realesrgan-ncnn-vulkan 版本忽略 -m 参数, 始终从 exe 旁
           models\{模型名}.param 根级加载; 这些模型的 param/bin 却在子目录
   - 修复: 把 4 个模型的 .param/.bin 复制到 models 根级; 移除 C# 中无效的 -m 逻辑
   - 验证: 58/58 全部通过

2. [严重] rpr_v7_2.3 张量不匹配
   - 现象: "Sizes of tensors must match... Expected 360 but got 368"
   - 根因: IFNet_v7_multi 内部把输入对齐到 16 的倍数但返回未裁剪帧
   - 修复: run.py 对 rpr_v7 手动 pad 到 16 对齐, 输出经 save_frame 裁回原尺寸
   - 验证: rpr_v7_2.3 输出 5 帧成功

3. [中] NvEnc HDR 参数钳制未生效
   - 现象: NvEncCommandBuilder.ClampParam(100-400) 从未被调用,
           UI 允许 0-200, 用户调到 0-99 会传给 NVEncC truehdr 导致失败
   - 修复: Build 内对 saturation/contrast 使用 ClampParam 钳制到 100-400

4. [低] RealEsrganCommandBuilder 字符串转义错误
   - 现象: 编译报 CS1002 (双引号未转义), 该修复代码从未编译通过
   - 修复: 转义字符串插值中的双引号

五、静态审查结论
------------------------------------------------
- 处理流水线 (拆帧/超分/补帧/合并/HDR/音频/回退): 逻辑完整
  * 拆帧 GPU 加速失败自动回退 CPU 并提示
  * 超分/补帧显卡错误自动单线程降级重试, 安全帧率可自动停止
  * rife-v4.25/v4.26 不受命令行版支持时自动回退 v4.6
  * 合并硬件编码失败自动回退 CPU libx265
  * 阶段完成后崩溃重跑自动跳过已完成步骤
- UI/导航/菜单/快捷键/清理/缓存检测/配置持久化: 正常
  * 处理中菜单清理项禁用, 完成后恢复
  * 临时目录缓存来源与当前视频不符时弹窗拦截
  * 模型/倍率/引擎选择即时保存到 appsettings
  * v2/v3 老模型倍率锁定 x2, 其他可用
- 构建产物: 版本1.0.4, 语言仅保留 zh-CN/zh-TW,
  Tools 自包含 (FFmpeg/NVEncC/officalrife+便携python/realesrgan/rife)

六、部署提醒
------------------------------------------------
realesrgan 模型的 .param/.bin 必须放置在 realesrgan-ncnn\models\ 根级
(随附工具版本忽略 -m 参数, 不识别子目录形式), 否则 x3/x4/x4plus 等模型无法加载。
