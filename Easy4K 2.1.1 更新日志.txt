                        Easy4K 2.1.1 更新日志
                  对比版本：2.1.0（2026-10-17）
                     发布日期：2026-10-17
════════════════════════════════════════════════════════════════════

发行包：Easy4K_2.1.1.0_x64.msix（x64 / 中文，11.59 GB）
适用平台：Windows 10 1809 及以上 / Windows 11

这是一个「功能补齐 + 问题修复」版本。新增孤儿定时任务与完整的远程控制
选项同步，把帧去重（SFDP）拆成可被外部程序调用的动态库，并修复了一批
编码参数、临时目录、远控状态不一致的问题。


────────────────────────────────────────────────────────────────────
一、新增功能
────────────────────────────────────────────────────────────────────

【1】孤儿模式：定时自动处理

    · 主页新增「将此任务添加为孤儿执行任务」按钮，选好启动时间即排队
    · 到点自动启动 Easy4K，按添加时的选项快照处理这支视频，跑完自动关闭
    · 任务一个接一个执行：前一个没跑完，后一个会等它结束再开始，不会同时开两个
    · 添加时会创建一个无窗口、不在任务栏显示的静默进程（Easy4K.Orphan.exe）
    · 删除最后一个任务时，后台进程自动退出

    日期与时间规则：
    · 只能排在当前年份内；选到今年之前 → 提示「今夕是何年?」
    · 选到明年及以后 → 提示「并非永远哦」
    · 确认框里写明完整启动时间（含年份）与串行执行说明

    临时目录：
    · 任务会记录添加时的临时目录 / 输出目录快照，到点按快照执行，
      不受之后改动设置的影响
    · 与已排队任务在同一块盘时，确认框会询问：
      「启动前强制清理 / 不清理，直接启动 / 取消」
    · 选择不清理时，若缓存明确来自别的视频，仍会强制清理一次，避免复用错误中间产物

【2】编码质量选项（高级页）

    · CPU 编码：CPU CRF（libx265 -crf）
    · 硬件编码：CQ / QP（NVENC 用 -cq / -qp，AMF 用 cqp，QSV 用 -global_quality）
    · 启用「使 FFmpeg 尝试使用 GPU 加速」后按显卡自动选择编码器：
      AMD → AMF，NVIDIA → NVENC，Intel → QSV
    · 没有可用硬件编码器或硬件编码失败 → 自动回退 libx265，并使用你设置的
      CRF 与速度预设（不是内置默认值）
    · 开启「使用 CPU 处理所有模型」时，CQ / QP 开关自动取消勾选并置灰，
      「CQ / QP 值」标签与说明文字一起变灰；CPU CRF 保持可用

【3】保留原视频内嵌字幕

    · 主页新增开关，成片里复制原视频的字幕流
    · 原视频没有字幕时自动禁用

【4】远程控制补齐

    · 支持域名与 IPv6 直连（服务端双栈监听）
    · 电脑端作为客户端时，文件夹选择、显卡检测全部改用远端数据
    · 协议补齐：去重档位（性能 / 完美）、音频超分精度（FP16 / FP32）、
      CPU CRF 与硬件编码 CQ·QP、保留字幕（含 hasSubtitles）
    · 选项反向同步：本机不再显示过期旧值
    · 开跑前就检查远端临时目录残留，不必等拆帧结束才发现
    · 服务端保留 lastResult 与 isProcessing：断线重连后能纠正
      「跑完了但仍显示进行中 / 主页没有成品」的界面

【5】帧去重（SFDP）拆成动态库

    · 新增 Easy4K.SFDP 独立库（OutputType=Library），主程序直接引用，
      两边行为永远一致
    · 编译产物单独放在 lib/Easy4K.SFDP/Easy4K.SFDP.dll，其他 .NET 程序
      可直接调用「相邻帧判重」能力
    · 新增 一键编译.bat / build-all.ps1：Debug + Release 全量编译并同步 DLL

【6】临时文件占用估算重做

    · 按实际输出分辨率与实测 PNG 体积（约 1.5 字节/像素）计算，
      1080p 约 3MB/帧、4K 约 12MB/帧
    · 超过 1024 GB 显示 TB；不足 1 GB 显示 MB
    · 修复长视频被算成「1600 GB」这类明显离谱的数字


────────────────────────────────────────────────────────────────────
二、问题修复
────────────────────────────────────────────────────────────────────

【补帧与编码】
    · 涡轮模式 PyTorch 补帧块把「安全帧率」误当成场景检测开关传入，
      同时漏传 --fp16；现改为 sceneDetect=false、--fp16 跟随「降低部分画质」
    · 「安全帧率」不再错接 PyTorch 轨的场景检测（默认关闭 scdet，
      避免运动中插出物理帧）
    · 高级性能选项补齐：PyTorch 轨补帧与单文件超分原先把部分选项丢掉
    · 涡轮块级流水在补帧 worker 异常时会卡死，现已能正确失败并联动取消
    · CPU 处理模式下仍能使用硬件编码相关选项，现已互斥

【AudioSR】
    · CPU 处理模式与 FP16 互斥：开启 CPU 后选 FP16 会弹窗说明并改回 FP32
    · 单文件超分的音频精度下拉框同步该规则（选 fp16 弹窗并改回 fp32），
      启动时也会纠正配置里的非法组合
    · 下拉框取值统一为小写 fp16 / fp32，与遥控协议和配置一致

【远程控制】
    · 电脑端远控：输入视频 / 输出 / 临时 / 帧文件夹四个入口都走远端选择器
    · 字幕开关在远端模式下能正常解锁
    · 新增选项能反向同步，不再显示本机旧值

【界面与操作】
    · 移除 Ctrl+O 打开视频快捷键（经常误触弹出文件选择框）
    · 设置页「每次开启 Easy4K 自动进入远程连接模式」开关与文字同排紧贴
    · 孤儿模式按钮移到按钮行最右侧；说明文字与「输出文件名」同一排右对齐
    · 超分提示行补上当前生效倍率，切换倍率必定刷新
    · Real-CUGAN 全体模型推荐星级降 1 星

【版本与发布】
    · 标题栏版本号改读程序集版本：MSIX 升级时旧配置不会让标题停在旧版本
    · 版本号统一到 2.1.1（csproj / AppxManifest / appsettings / 随包声明文档）


────────────────────────────────────────────────────────────────────
三、行为变化（升级前请留意）
────────────────────────────────────────────────────────────────────

    1. 硬件编码器不再手动选择，改为按显卡自动选择（NVENC / AMF / QSV）；
       没有可用硬件编码器时自动回退 CPU（libx265 + 你的 CRF）
    2. 开启 CPU 处理模式时，CQ / QP 会被取消勾选并禁用；关闭 CPU 模式后
       不会自动勾回，需要重新选择
    3. 孤儿任务只能排在当前年份内
    4. 临时占用估算数值比 2.1.0 更大（此前按 1 字节/像素低估了约 1/3）
    5. 帧去重不再提供独立 exe，改为动态库 + 主程序内直接调用


────────────────────────────────────────────────────────────────────
四、安装说明
────────────────────────────────────────────────────────────────────

    商店版：由 Microsoft Store 签名并安装，直接更新即可
    本地测试（未签名包）：
        Add-AppxPackage -Path Easy4K_2.1.1.0_x64.msix -AllowUnsigned
        （需在系统设置中开启「开发人员模式」）

    安装目录只读；配置、临时文件、输出、日志统一落在
    %LOCALAPPDATA%\Easy4K（便携版仍使用 exe 同级目录）
